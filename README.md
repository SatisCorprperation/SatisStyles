# SatisStyles

This program is a multi platform web server application powered by next.js

## Usage
First, download and install node.js and the source code zip from the releases section. Then extract the zip and open a terminal in the folder of the zip. Finally run the commands below and navigate to the URL shown in your web browser:

```bash
npm ci # or npm install
npm start
```

## Designer
The tool was designed to combat the hate that some have of manually writing out CSS. This tool allows you to make CSS files based on selections. The UI will allow you to create elements, Define their `font-family`, `color`, `font-size` and `background-color`. Then you will be able to add other features like `display` and more. __Please note that this software is not ready for public release__
