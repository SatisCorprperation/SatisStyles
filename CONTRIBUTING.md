# Contributing

Thanks for helping improve SatisStyles.

## Development setup

1. Install Node.js 18.17 or later and npm.
2. Create a branch for your change.
3. Install dependencies with `npm install`.
4. Start the development server with `npm run dev`.

## Before opening a pull request

- Run `npm run build` and confirm it completes successfully.
- Run `npm test`. This command is currently a placeholder; add or run focused checks when your change introduces testable behavior.
- Update the README when setup steps or user-facing behavior change.
- Keep changes focused, and follow the existing Next.js and React patterns.
- Describe what changed and any checks you ran in your pull request.

Open a pull request for review rather than committing directly to the default branch. Respond to reviewer feedback and update the change as needed.
